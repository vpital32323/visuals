Troizy Visuals — Fabric 1.20.1

Сборка через GitHub:
  1) Залей все файлы в репозиторий (вместе с папкой .github)
  2) Вкладка Actions -> Build mod -> дождись зелёной галочки
  3) Внизу страницы запуска в Artifacts скачай troizy-visuals (внутри jar)

Установка: jar в папку mods + Fabric Loader 0.14.21+ и Fabric API (1.20.1).
Меню: Right Shift. Название визуалов: Settings.java -> NAME.
